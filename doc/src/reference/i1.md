# I1

`I1` represents electric current, one of the SI base dimensions. The
user-facing alias is `ElectricCurrent<V, U>`, where `V` is the numeric storage
type and `U` is an electric-current unit.

## Units

The dimension provides these unit markers:

| Unit | Abbreviation | Scale to ampere |
| --- | --- | --- |
| `Ampere` | `A` | `1.0` |
| `Milliampere` | `mA` | `1e-3` |
| `Microampere` | `µA` | `1e-6` |

## Operations

I1 quantities support the standard operations provided to every dimension:

- addition and subtraction of quantities with the same unit;
- multiplication and division by the underlying numeric value;
- compound assignment forms of those operations; and
- division of two quantities with the same unit, returning the numeric value.

Linear conversion implementations are generated for the registered ampere and
milliampere conversion pair. Other conversions can be added explicitly as the
unit set evolves.
